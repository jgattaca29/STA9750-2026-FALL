Step 1: Load Data

#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
  
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
  
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
    mutate(path = path(data_dir, paste0(period, ".xlsx")), 
           path = map2(url, path, download_if_needed), 
           data = map(path, read_excel, skip=3, na="*"), 
           data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

Step 2: Exploratory Questions of the Dataset

We wish to understand the dataset on a deeper level than these surface insights. For that, we will use several functions to find out facts that enhance our understanding. For starters, we will find out the date range covered in the set:

range(NETFLIX_DATA$period_start, NETFLIX_DATA$period_end, na.rm = TRUE)

We can see now that the dates covered range from “2023-01-01” to “2026-06-30”.

Now we are going to find out the amount of different shows and movies in the dataset. Keep in mind that Netflix has a practice of renaming show seasons. As a fun fact, this is a strategy to reset the show’s respective season into it’s “own show”, as it helps them circumvent royalty fees for the staff involved in a show production.

number_titles <- n_distinct(NETFLIX_DATA$Title)
Warning: Unknown or uninitialised column: `Title`.

With this command, we can see that there are 24,427 titles in the dataset.

Now, say we want to find out how many watched hours does the Bridgerton series of shows contains. We can use the following function to find out:

bridgerton_total_hours <- NETFLIX_DATA |> 
filter(str_detect(title,'Bridgerton')) |> 
summarize(total_hours = sum(hours_viewed, na.rm = TRUE)) |> 
pull(total_hours)

The str_detect function helps us include the keyword ‘Bridgerton’ to have RStudio include any title that contains the keyword and include it into the sum. We can see that Bridgerton has 4.8628 billion total hours.

We can use a similar process for the core Stranger Things show. However, we are going to exclude the spin-off shows, as well as the “show” where it plays background music for people who like something going on in the background of their screens while they do something else. We use a series of filter in function to have R include our desired title, while we use filter out to exclude the spin-off shows.

stranger_things_total_hours <- NETFLIX_DATA |>
filter(str_detect(title, "Stranger Things")) |>
filter_out(str_detect(title, "Beyond Stranger Things")) |>
filter_out(str_detect(title, "Tales from '85")) |>
filter_out(str_detect(title, "Stranger Things: Fireplace")) |>
summarize(total_hours = sum(hours_viewed, na.rm = TRUE)) |>
pull(total_hours)

We can see that the core Stranger Things show has collected a total of 5.5889 billion views across 5 seasons. It is easy to see why it was the crown jewel for Netflix ever since its inception.

It is easy to notice how flagship titles for Netflix have yielded results for the streaming platform. Now, we wish to bring focus a bit closer to the present state of the platform. Thus in the following code, we create an object where we filter the titles down to one period, the first half of 2026. Afterwards, we use the slice_max function to limit the amount of titles displayed in the tibble to the top 10. Using mutate, we can create a percentage of how much of the viewership each title commanded during the time period. Finally, we display the object using the respective variables of interest.

##Memo

Our exploration of the dataset has generated insights that provide Netflix leadership with valuable information on how to proceed on decision-making for the approval of future projects. As Netflix continues to seek more market cap not only from the television markets, but also the film market, it is important to understand the existing viewership data built over the past three years. It is imperative that Netflix continues to seek novel productions that can translate into multiple seasons while remaining consistent towards production values that can yield feasible projects that feed viewers’ desire for fulfilling stories while expanding into the live television market.

As it is well-known, a recent development that Netflix has gone forward in the past month is the obtaining of FIFA World Cup Match Streaming rights for the 2030 edition of the tournament. This is a significant step into the right direction for Netflix, as the World Cup generates a storyline of drama and excitement with every match. As it currently stands, it appears that these rights will be exclusive in the United States. It will be crucial for Netflix to take the steps towards ensuring their hold of the rights extends towards markets outside the United States, as it will continue to pay dividends in markets harder to capture. The difficulty will be that the television-holders in strong markets such as Europe will seek securities that allow them to maintain the rights towards the 2030 edition of the tournament.

As for original content, it will be just as crucial to find the next franchise that can command the global audience’s attention while being fully owned by Netflix. The most seen IP in Netflix’s catalogue for the past 3 years has been Bridgerton. However, this show is only licensed by Netflix, it is not fully owned the way Stranger Things is. Originally, the plan for Netflix was to buy Warner Bros in order to gain access to its IP catalogue, out of which the DC Comics characters were a main draw for possible projects that are longer focused (meaning over 30 minutes and serialized storytelling). This is the type of content that still dominates up to the first half of 2026, thus it is paramount to continue to grow in this area. Although the line between television and film continues to blur, the top 10 list is still dominated by the series format. There have been prior attempts by Netflix to utilize superhero IP’s, such as Millarworld, the production company by comic books writer Mark Millar. Since the efforts from Millarworld did not translate into sustainable projects (Such as Jupiter’s Legacy, which was canceled after 1 season), it is best for Netflix to continue seeking feasible pitches that can connect with viewers. Out of all the tasks in entertainment, finding the right pitch will always be the most difficult task, thus it is important to seek originality as the cornerstone of the next initiative that can yield a project similar to Stranger Things.
